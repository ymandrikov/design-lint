# Quickstart: Validate the shared.js Refactor

This is a **behavior-freeze** refactor. Validation = prove output and types are identical
before and after, and prove no trace of the old module remains.

## Prerequisites

- `pnpm install` done; Node `^26.1.0`.
- Clean working tree at the pre-refactor commit (to capture the baseline).

## Step 1 — Capture the baseline (before touching code)

```sh
pnpm typecheck
pnpm test
node lint-color/index.js fixtures/demo-app > /tmp/demo-before.txt 2>&1; echo "exit=$?"
```

Record: test pass count, and `/tmp/demo-before.txt` + its exit code. This is the oracle.

## Step 2 — Apply the refactor

Follow `tasks.md` (generated by `/speckit-tasks`). In short: create `ansi.js` + `files.js`,
inline the dispatch gates into `linter.js`, move `runTokenRuleOnSource` into `helpers.ts`,
repoint all importers to owning modules, delete `shared.js`.

## Step 3 — Validate behavior freeze

```sh
pnpm typecheck        # expect: zero errors
pnpm test             # expect: same pass count, no assertion edits, no skipped/.only
node lint-color/index.js fixtures/demo-app > /tmp/demo-after.txt 2>&1; echo "exit=$?"
diff /tmp/demo-before.txt /tmp/demo-after.txt   # expect: NO output (identical), same exit code
```

**Pass criteria** (maps to Success Criteria):

- `diff` empty + identical exit code → SC-002.
- `pnpm typecheck` / `pnpm test` / `pnpm lint:demo` green → SC-003.

## Step 4 — Validate the module cleanup

```sh
test ! -e lint-color/shared.js && echo "C-1 ok: shared.js deleted"
rg -n "shared\.js" lint-color tests && echo "FAIL: references remain" || echo "C-2 ok: 0 references"
rg -n "re-exported here|so existing importers keep working" lint-color && echo "FAIL: shim comment remains" || echo "SC-004 ok: no shim comments"
```

**Pass criteria**:

- `shared.js` gone (C-1), 0 references (C-2 / SC-006), 0 shim comments (SC-004).

## Step 5 — Spot-check single-concern homes (SC-005)

```sh
rg -n "readdirSync|extname" lint-color/ansi.js && echo "FAIL: fs concern leaked into ansi.js" || echo "ansi.js single-concern ok"
rg -n "\\x1b\\[" lint-color/files.js && echo "FAIL: styling leaked into files.js" || echo "files.js single-concern ok"
```

A reader locating any former-`shared.js` utility now lands on `ansi.js`, `files.js`,
`helpers.ts`, `linter.js`, `ast.js`, or `classify.js` — never a generic grab-bag.
